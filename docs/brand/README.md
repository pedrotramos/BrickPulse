# Logo do BrickPulse

Símbolo Frequência: cinco barras arredondadas, como amplitudes de um sinal
amostrado, em laranja `#B94B2C`. A cor do logo é separada do acento petrol da
interface.

| Arquivo | Uso |
| --- | --- |
| `brickpulse-symbol-color.svg` | Símbolo em cor. É idêntico a `frontend/public/favicon.svg`, que o app usa na barra lateral e como favicon. |
| `brickpulse-symbol-mono.svg` | Símbolo em uma cor. |
| `brickpulse-symbol-reversed.svg` | Símbolo branco, para fundos escuros (fundo transparente). |
| `brickpulse-lockup-*.svg` | Símbolo com o nome, nas mesmas três versões. |

Não redesenhe, recolora nem combine o símbolo com outra marca. As assinaturas
(`lockup`) embutem a fonte Instrument Sans em WOFF2, sob a SIL Open Font License
1.1 (`FONT-LICENSE.txt`).
